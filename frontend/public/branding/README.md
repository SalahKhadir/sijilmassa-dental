# Logo officiel

Placer le fichier fourni par le cabinet dans ce dossier avec le nom `sijilmassa-dental-logo.svg`, ou avec son extension réelle `.png` ou `.webp`.

La détection suit cet ordre, SVG puis PNG puis WebP. Relancer le serveur de développement ou reconstruire le frontend après l’ajout ou le remplacement du fichier.

Le composant `Brand` affiche le fichier dans ses couleurs originales avec `object-contain`. Le fond blanc permet son utilisation sur le panneau bordeaux. Le nom du cabinet sert de repli accessible lorsque le fichier est absent ou lorsque son chargement échoue.
